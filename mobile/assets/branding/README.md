# Yowell Rent-Car brand assets

These files were prepared from the supplied logo:

- `yowell-rent-car-source.jpg` — original source image, kept for reference.
- `yowell-lockup.png` — cleaned transparent master for splash and brand
  surfaces.
- `casa-rivas-rent-car-logo.png` — optional reference lockup; it is not used
  by the internal app screens.
- `casa-rivas-rent-car-splash.png` — optional reference splash; the app keeps
  using the original `../splash.png`.
- `casa-rivas-rent-car-app-icon.png` — black-and-gold app icon lockup with the
  CR crest, Casa Rivas name and “Rent Car” descriptor.
- `casa-rivas-rent-car-adaptive-icon.png` — Android adaptive icon using the
  same black-and-gold lockup.
- `../images/logo.png` — fixed 500 × 500 transparent in-app logo.
- `../icon.png` and `../icon-ios.png` — fixed 1024 × 1024 light/blue app icon
  variants.
- `../adaptive-icon.png` — fixed 1024 × 1024 Android adaptive foreground
  treatment on Yowell blue.
- `../splash.png` — fixed 1284 × 2778 dark splash treatment with the Yowell
  lockup and red accent.

The original package identifiers and Expo scheme remain unchanged to preserve
existing installs, OTA updates and store configuration. Only the visible brand
name, colors and assets were updated in this phase.
